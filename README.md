## The entry

One sentence (159 characters) that explains the modern internet to a
time traveler from 1800 — built only from what 1800 already knows: a
road, a library, a post office, a letter, a door, a table.

> Imagine one road joining every library and post office on earth, so any letter reaches any door faster than a blink, and a great library opens upon your table.

## How it runs

`main.ts` (Node 22) writes exactly that one sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `output/entry.txt` when run by
hand), validates the 1–200 character gate and the single-sentence
rule first, and verifies the write round-trips byte for byte, so two
runs produce byte-identical output.

```sh
node main.ts
```
